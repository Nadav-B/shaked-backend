# Shaked Service

**Authors**: Nadav Babai 

A controller to handle data for shaked web application

### Build, Run Test

- Build Service
```bash
gradlew clean build
```
- Run Unit Tests:
```bash
gradlew clean test
```
- Run Service (Docker-Compose Services vorher starten)
```bash
gradlew bootRun
``` 

- running docker 
```bash
docker-compose up
``` 

### Tech-Stack
- [Java 17](https://openjdk.java.net/projects/jdk/17/)
- [GraphQL](https://graphql.org/)
